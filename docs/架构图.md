## 3. SQL 安全校验引擎（核心防御）

```mermaid
flowchart TB
    Input["用户 SQL<br/>(AI 生成 / 手动编写)"]

    Pre["Layer 1 预处理<br/>去注释/空行"]

    Parse{"JSqlParser<br/>语法解析成功?"}

    R1["❌ REJECT<br/>语法错误"]

    Type["Layer 3 语句类型<br/>⚠️ 仅允许 SELECT"]

    R2["❌ REJECT<br/>DML/DDL 拦截"]

    Dialect["Layer 4 方言校验<br/>匹配数据源类型"]

    R3["❌ REJECT<br/>方言不兼容"]

    Object["Layer 5 对象存在性<br/>遍历 Table/Column<br/>匹配元数据"]

    R4["❌ REJECT<br/>引用不存在对象"]

    Risk["Layer 6 高危逻辑<br/>笛卡尔积/全表扫描"]

    AutoFix{"自动修复?"}

    Fix["自动修复<br/>追加 LIMIT 1000"]

    Out["输出<br/>PASS/WARNING/REJECT<br/>+ fixed_sql"]

    Input --> Pre --> Parse
    Parse -->|否| R1
    Parse -->|是| Type --> R2
    Type --> Dialect --> R3
    Dialect --> Object --> R4
    Object --> Risk --> AutoFix
    AutoFix -->|是| Fix --> Out
    AutoFix -->|否| Out

    classDef reject fill:#ffcdd2,stroke:#c62828,color:#000
    classDef core fill:#fff3e0,stroke:#ef6c00,color:#000
    class R1,R2,R3,R4 reject
    class Pre,Parse,Type,Dialect,Object,Risk,Fix,AutoFix core
```

## 4. 全链路业务流程（NL2SQL 查询）

```mermaid
sequenceDiagram
    actor U as 用户
    participant FE as 前端
    participant BE as 后端
    participant AI as Spring AI
    participant LLM as LLM 服务
    participant DS as 数据源适配
    participant DB as 目标库(只读)

    U->>FE: 添加表 + 配置字段
    U->>FE: 输入自然语言
    U->>FE: 点击【生成SQL】
    FE->>BE: POST /api/workspace/generate-sql
    BE->>BE: 构建 Prompt (tables/meta/filters/joins/nl)
    BE->>AI: 调用 LLM
    AI->>LLM: chat completion
    LLM-->>AI: 生成 SQL
    AI-->>BE: 返回 SQL 文本
    BE-->>FE: 回写至 SQL 编辑框

    U->>FE: 编辑/确认 SQL
    U->>FE: 点击【执行SQL】
    FE->>BE: POST /api/sql/exec { sql }

    Note over BE: SqlSecurityService<br/>(检查+执行共用)

    BE->>BE: 安全校验 7 层
    alt REJECT
        BE-->>FE: 错误信息，不执行
    else WARNING
        BE-->>FE: 弹窗确认
        U->>FE: 确认执行
    else PASS
        BE->>DS: 获取连接
        DS->>DB: 执行 SELECT (15s 超时)
        DB-->>DS: 结果集
        DS-->>BE: 数据行
        BE-->>FE: 渲染至结果展示区
        BE->>BE: 记录操作日志
    end

    opt 用户导出
        U->>FE: 点击【导出数据】
        FE->>BE: POST /api/export/query
        BE->>BE: EasyExcel 流式写文件
        BE-->>FE: 下载 .xlsx/.csv
    end
```
