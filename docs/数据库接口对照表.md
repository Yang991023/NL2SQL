## 2. 详细对照(按表)

### ① `public.t_table_meta`  (行数 974)
**用途:** 缓存从外部数据源同步的表结构(列、类型、注释、PK)。所有 SQL 生成都要从这里取列元数据。

| 字段 | 类型 | 约束 |
|---|---|---|
| id | int8 | PK |
| data_source_id | int8 | NOT NULL |
| database_name | varchar(100) | NOT NULL |
| schema_name | varchar(100) | NULL |
| table_name | varchar(200) | NOT NULL |
| table_comment | varchar(1000) | NULL |
| columns_json | text | NULL, 列定义 JSON 数组 |
| synced_at | timestamp | NULL |
| created_at | timestamp | NULL |
| updated_at | timestamp | NULL |

**唯一索引:** `(data_source_id, database_name, schema_name, table_name)` / `(data_source_id, database_name, table_name)`

**写入接口 (内部调用):**
| HTTP | 路径 | 说明 |
|---|---|---|
| POST | `/api/meta/{dsId}/sync` | 调外部数据源拉库表清单 → 写本表 |
| POST | `/api/datasource/{id}/refresh-meta` | 刷新单个数据源 → 写本表 |

**读取接口:**
| HTTP | 路径 | 读哪些列 |
|---|---|---|
| GET | `/api/meta/{dsId}/databases` | database_name |
| GET | `/api/meta/{dsId}/schemas?database=` | schema_name |
| GET | `/api/meta/{dsId}/tables?database=&schema=` | table_name |
| GET | `/api/meta/{dsId}/table?database=&schema=&table=` | 全表(含 columns_json) |
| (内部) | `SqlGenerateService.buildTableMeta` / `buildFullFieldMeta` | columns_json |

## 4. 字段流转图(以"自然语言生成 SQL"为例)

```
前端 (QueryCanvas.tsx)
  ↓ POST /api/workspace/generate-from-nl
  { dataSourceId, projectTableId, tables, fields, userNlQuery, skillId }
  ↓
WorkspaceController
  ↓
SqlGenerateService.generateFromNl
  ├─ if projectTableId != null:
  │    └─ projectMetaRepo  → t_project_table_meta     (取表名/项目编号/项目名)
  │    └─ projectFieldRepo → t_project_table_field    (取字段+业务描述)
  └─ else:
       └─ dataSourceRepo    → t_data_source           (取 db_type)
       └─ tableMetaRepo     → t_table_meta            (取列)
       └─ fieldBizMap       → t_field_biz_meta        (取业务描述)
  ↓
SkillTemplateService.getDefault / getByName
  └─ t_skill_template                                    (取 Prompt 模板)
  ↓
AiClient
  └─ t_llm_config                                        (取 base_url/api_key/model)
  ↓
返回 { sql, prompt, warnings }
```
